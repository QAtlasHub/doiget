doiget

DOIs and arXiv ids → local PDFs, through official APIs.
The agent-facing companion to BiblioFetch.jl. 

$ doiget fetch 10.1103/PhysRevLett.130.200601
wrote ~/papers/2L/2LpQ.../paper.pdf  (412 KB, license: cc-by)
Posture. doiget does not bypass paywalls, host content, run as a SaaS, or bundle publisher API keys. Open Access by default; TDM credentials are user-supplied and compile-time opt-in. Read the scope & legal page.

Who is reading this?

End user

Use the CLI to fetch papers by DOI or arXiv id. Install, batch, inspect what landed.

Developer

Wire doiget into an agent host (Claude Desktop, Cursor, Codex) via MCP, or use doiget-core from Rust.

Contributor

Read the architecture, the phase plan, and the ADRs before sending a PR.

Why doiget?

  • OA-first by default; institutional TDM is opt-in and compile-time gated.
  • Cryptographic provenance log (JSON Lines + SHA-256 hash chain, fail-closed).
  • Shares its on-disk store format with BiblioFetch.jl — same ~/papers/ directory.
  • No telemetry, no auto-update, no phone-home (ADR-0015).
  • Single static binary; stdio-only MCP server.
