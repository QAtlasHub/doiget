pub fn load(config_path: &Utf8Path) -> Result<VerifyConfig, VerifyConfigError>
Expand description

Load the [verify] section from config_path.

A missing file yields VerifyConfig::default (not an error), so a user who never wrote a config.toml gets the lenient defaults. A present-but-malformed file is an error the caller surfaces (verify degrades to defaults with a warning rather than aborting).
