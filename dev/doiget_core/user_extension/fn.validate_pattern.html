pub fn validate_pattern(pattern: &str) -> Result<(), PatternError>
Expand description

Validate a host pattern per ADR-0028 D2-1.

Accepted shapes:

  • Literal FQDN: example.org, ruj.uj.edu.pl. Only [A-Za-z0-9.-], at least one ., no empty / hyphen-bordering labels.
  • Single-suffix wildcard: *.example.org. The * MUST be the first character, MUST be followed by ., and MUST be the only * in the pattern.

§Errors

Returns the closed-enum PatternError for any rejected input.
