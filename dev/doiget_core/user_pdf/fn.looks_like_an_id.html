pub fn looks_like_an_id(stem: &str) -> bool
Expand description

Whether stem reads as a work id rather than a description: six or more characters, only letters, digits, ., - and _, and at least one digit. BF01397394, PhysRev.34.1293 and rspa.1950.0036 are ids; 1928-024 PCPS Hartree - The wave mechanics is not.
