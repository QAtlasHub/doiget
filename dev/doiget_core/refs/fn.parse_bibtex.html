Parse a BibTeX / BibLaTeX document via the biblatex crate (ADR-0030 D2). One @entrytype{KEY, …} produces one entry; entry_key is the citation key verbatim.

A whole-input parse failure (malformed BibTeX the biblatex crate rejects) is returned as a single-element ParseError::Decode so the caller’s exit-code path counts it as one error rather than zero — matching the CSL-JSON behaviour.

Identifier-pick priority per ADR-0030 D3: doi field, then eprint (arXiv). See parse_bibtex_entry.
