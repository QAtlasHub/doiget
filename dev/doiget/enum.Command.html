Variants§

§

Fetch

Fetch a single paper PDF by DOI or arXiv id.

Fields

§ref_: String

DOI (e.g. “10.1234/example”) or arXiv id (e.g. “arXiv:2401.12345”).

§dry_run: bool

Build a fetch plan and emit it as JSON on stdout without touching the network, the store, or the provenance log (ADR-0022). The plan.pdf_sources[].candidate_hosts list is the static allowlist for the resolver, not a prediction of the single host the real fetch would hit (ADR-0022 §4).

§link: Option<Utf8PathBuf>

After fetching, also place a link to the PDF in DIR (created if missing) so it is visible in your working tree. Uses a symlink, falling back to a copy where symlinks are unavailable (e.g. Windows without privilege). Named from the paper’s metadata (e.g. vaswani2017-attention-is-all-you-need.pdf), or the safekey when metadata is absent. Metadata-only fetches (no PDF) are skipped. (#344)

§

Batch

Fetch many refs from a newline-separated text file.

With --json, records are written as each ref COMPLETES, not in input order: up to 5 fetches run concurrently and a parse error returns instantly where a 1 MB PDF does not. Key on the ref field of each record; zipping stdout against the input file positionally attaches results to the wrong DOI (#479).

Fields

§path: String

Path to a file containing one ref per line.

§dry_run: bool

Emit one fetch-plan JSON envelope per ref on stdout without touching the network, the store, or the provenance log (ADR-0022). Per-ref parse failures still cause a non-zero exit so a malformed batch is visible.

§only_failed: bool

Skip refs that already have a PDF in the store (<store>/<safekey>.pdf exists). Metadata-only entries are NOT skipped — they may now succeed via the preprint fallback or allowlist updates. Use after a partial batch run to re-attempt only failures without wasting API budget on already-fetched refs (issue #324).

§delay: Option<f64>

Seconds to sleep between individual fetches. Useful for hosts that throttle below the HTTP 429 threshold (issue #326).

§user_agent: Option<String>

Override the User-Agent header for every HTTP request in this batch. Default: doiget/<version> (+https://github.com/QAtlasHub/doiget).

§

Info

Show metadata for a stored entry.

Fields

§ref_: String

DOI or arXiv id.

§

ListRecent

List the most recently fetched entries.

Fields

§limit: usize

Number of entries to show.

§missing_pdf: bool

Show only entries with no stored PDF – the metadata-only ones.

Answers “which of my batch need retrying?” without reading a fifty-row table by eye. The pdf column carries the same information for every row (#481).

§

Search

Search for papers. Default: external discovery over OpenAlex (/works?search=, ADR-0031) — turn a topic into ranked candidate papers with abstracts. Use --local to scan the local store (title / authors / venue) instead.

Fields

§query: String

Query string (a topic for discovery, or a substring for --local). May be empty when --local --tag is given (matches all tagged entries).

§local: bool

Scan the local store instead of external discovery.

§external: bool

Explicit form of the default external discovery (mutually exclusive with --local).

§tag: Option<String>

Filter local-store results to entries tagged with this tag (case-sensitive). Requires --local.

§limit: usize

External: maximum results. Must be 1..=200 (OpenAlex’s per-page cap); an out-of-range value is rejected, not clamped.

§from_year: Option<i32>

External: only works published in or after this year.

§to_year: Option<i32>

External: only works published in or before this year.

§oa_only: bool

External: restrict to open-access works.

§min_citations: Option<u64>

External: only works cited strictly more than this many times.

§min_fwci: Option<f64>

External: minimum field-and-year-normalized impact (FWCI). A quality FILTER (not a sort) — fwci:>{f}. See #290.

§min_percentile: Option<u8>

External: minimum within-cohort citation percentile (0–100), i.e. top-X% among same-year works (cited_by_percentile_year). Combine with --from-year for “recent and already standing out”. See #290.

§author: Option<String>

External: filter to an author by name (resolved to an OpenAlex author ID via /authors?search=).

§venue: Option<String>

External: filter to a venue / journal by name (resolved to an OpenAlex source ID via /sources?search=).

§publisher: Option<String>

External: filter to a publisher by name (resolved to an OpenAlex publisher ID via /publishers?search=).

§sort: SortArg

External: result ordering.

Bib

Export stored entries as BibTeX. A single ref, the whole store (--all), or a ref list (--from-file) — all rendered offline from the local store (#305).

Fields

§ref_: Option<String>

DOI or arXiv id. Omit when using --all or --from-file.

§all: bool

Export every entry in the store as one deduplicated .bib.

§from_file: Option<Utf8PathBuf>

Export the refs listed in FILE (one per line, or CSL-JSON / BibTeX), each rendered from the store; missing entries are skipped (and counted toward the exit code).

§

Cite

Resolve a ref live and print a clean BibTeX entry (doi2bib-style). Falls back to the local store when the live resolve fails, so an already-fetched ref always cites (#305).

Fields

§ref_: String

DOI or arXiv id.

§offline: bool

Skip the live resolve and render from the local store only (errors if the ref was never fetched).

§

Csl

Export stored entries as CSL JSON. A single ref, the whole store (--all), or a ref list (--from-file) — all rendered offline from the local store (#305).

Fields

§ref_: Option<String>

DOI or arXiv id. Omit when using --all or --from-file.

§all: bool

Export every store entry as one deduplicated CSL JSON array.

§from_file: Option<Utf8PathBuf>

Export the refs listed in FILE (one per line, or CSL-JSON / BibTeX), each rendered from the store; missing entries are skipped (and counted toward the exit code).

§

Text

Extract a paper’s full text from ar5iv as sectioned plain text (the #281 “read” step; ADR-0032). Takes an arXiv id; the PDF blob is never opened. A bare DOI reports NO_OA_AVAILABLE (pass the arXiv id). Tier-1 OA, always-on.

Fields

§ref_: String

arXiv id (e.g. “arxiv:2401.12345”). A DOI is reported as having no full-text source yet (#281 item 5).

§max_chars: Option<usize>

Cap the section body text to this many characters (the title and section headings are not counted; truncation is flagged on truncated). Omit for the full text.

§no_cache: bool

Bypass the on-disk text cache (always re-fetch from ar5iv).

§

Frontier

Discover the frontier neighbourhood of a seed paper: surfaces papers that cite the seed, ranked by age-normalized impact (fwci), excluding papers already in the local store (#295).

Fields

§doi: String

Seed DOI (e.g. “10.1103/PhysRevB.1”).

§limit: usize

Maximum results to return (1–200; default 25).

§from_year: Option<i32>

Only include works published on or after this year.

§

TexSource

Fetch the raw LaTeX source of an arXiv paper directly from the arXiv source API (export.arxiv.org/src/<id>). More reliable than text (ar5iv HTML) for papers not yet processed by LaTeXML. PDF-only submissions yield TEXT_UNAVAILABLE. Tier-1 OA, always-on.

Fields

§ref_: String

arXiv id (e.g. “arxiv:2401.12345”). A DOI reports NO_OA_AVAILABLE.

§max_chars: Option<usize>

Cap the returned LaTeX source to this many characters (truncation is flagged, never silent). Omit for the full source.

§no_cache: bool

Bypass the on-disk TeX source cache (always re-fetch).

§

Source

Download an arXiv submission’s source bundle (every file) or just its figures to a directory. Fetches the same /src/<id> tarball as tex-source (one request) and materialises files to --out. Files are written opaque (never interpreted); tar entry paths are sanitised (zip-slip safe, ADR-0034). PDF-only submissions yield TEXT_UNAVAILABLE. A DOI reports NO_OA_AVAILABLE. Tier-1 OA, always-on. --mode json emits {ok, arxiv_id, out_dir, figures_only, count, files[]}.

Fields

§ref_: String

arXiv id (e.g. “arxiv:2401.12345”). A DOI reports NO_OA_AVAILABLE.

§out_dir: Utf8PathBuf

Directory to write the extracted files into (created if missing).

§figures_only: bool

Extract only image/figure files (.pdf .eps .ps .png .jpg .jpeg .gif .svg), not the full source bundle.

§

Link

Resolve a DOI to its arXiv preprint + identity cluster (OpenAlex; #281 item 5). Reports whether the same work has a free arXiv preprint, for reading or dedup. arXiv → DOI is a follow-up.

Fields

§ref_: String

DOI (e.g. “10.1103/PhysRevB.1”). A non-DOI ref is rejected.

Verify

Verify that every DOI / arXiv reference in a bibliography file (.bib / CSL-JSON / plain refs) resolves to real metadata. Does not download PDFs or write to the store. Emits one JSON-Lines record per entry; exits non-zero on failures.

Fields

§path: String

Path to the bibliography file to verify.

§format: String

Input format; auto-detected from extension / content by default.

§strict: bool

Treat unresolved and id-less entries as failures (exit non-zero), not just warnings. Use in a network-stable CI lane.

§

Lint

Structurally validate a BibTeX bibliography (duplicate keys, missing fields, blank entries, $$ title math) WITHOUT resolving DOIs or touching the network. Read-only; emits one JSON-Lines finding per issue and exits non-zero on errors.

Fields

§path: String

Path to the BibTeX file to lint.

§strict: bool

Promote warnings to errors so any finding fails the run.

Tag

Assign or remove tags and collections on a stored entry (#294).

Positional <tag>... arguments add tags. Use --remove to remove. Use --collection / --remove-collection for collection membership. Use --list to show current tags, collections, and annotation.

Fields

§ref_: String

DOI or arXiv id.

§tags: Vec<String>

Tags to add (idempotent). Positional — may repeat.

§remove: Vec<String>

Tags to remove.

§collection: Vec<String>

Collections to join (idempotent).

§remove_collection: Vec<String>

Collections to leave.

§list: bool

Show current tags, collections, and annotation; no mutation.

Fields

DOI or arXiv id.

§text: Option<String>

Annotation text (replaces any previous annotation).

§clear: bool

Clear the annotation (remove it from the TOML).

Capabilities

Emit a single JSON inventory of the binary’s full surface (subcommands, args, env vars, modes, MCP tools, features). Designed for LLM cold-boot in one round-trip. See #214.

§

Config

Show or doctor the resolved configuration.

Fields

§action: String

init / show / path / doctor

§force: bool

init only: overwrite an existing config.toml. Without this, init refuses rather than replace a file that may hold a hand-written allowlist (issue #408).

§network: bool

doctor only: also run the outbound network report — proxy configuration, Unpaywall pool, allowlist coverage, and one GET per well-known publisher to show which will talk to a scripted client (issue #407). Opt-in because it makes real requests.
