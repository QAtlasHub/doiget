Struct Server

pub struct Server { /* private fields */ }
Expand description

MCP server handle. Owns the resolved CapabilityProfile plus the statically-built rmcp tool router.

Construct via Server::new and drive with Server::run:

let profile = doiget_core::CapabilityProfile::from_env()?;
doiget_mcp::Server::new(profile).run().await

pub async fn run(self) -> Result<()>

Run the MCP server until stdin reaches EOF.

Returns once the underlying rmcp service loop exits — that happens either when the peer (MCP host) closes stdin, or when the service is cancelled via the rmcp lifecycle. Callers are expected to invoke this from the binary’s main() and surface any error via the process exit code.

§Errors

Returns an error if rmcp service initialization fails (e.g. the stdio handles are unavailable) or if the service loop terminates abnormally.
