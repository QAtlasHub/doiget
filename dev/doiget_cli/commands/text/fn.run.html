Run the text subcommand.

§Errors

Surfaces a typed ErrorCode as a process exit code via CliExit: an invalid ref is a usage error; a DOI yields NO_OA_AVAILABLE; an ar5iv render with no extractable prose yields TEXT_UNAVAILABLE (never a silent exit-0 — issue #302) with an actionable “fetch the PDF” note; other extraction failures map through ErrorCode::from.
