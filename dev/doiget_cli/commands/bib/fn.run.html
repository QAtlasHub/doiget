Run the bib subcommand against the configured store.

Exactly one selector must be supplied: a positional ref_, --all, or --from-file. The BibTeX output is product output (the requested artifact), not informational, so Quiet does NOT suppress it. A missing single entry — or any missing ref under --from-file — yields a non-zero exit (never a silent empty stdout: the #302 / #304 contract).
