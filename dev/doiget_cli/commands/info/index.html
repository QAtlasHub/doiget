doiget info <ref> subcommand — read-only metadata inspection.

Reads the metadata TOML for a given Ref from the FsStore and prints it on stdout. Network access is never required.

Per docs/PUBLIC_API.md §2 the read goes through the Store::read trait method, so any future store backend (e.g. a SQLite index in Phase 2) is a drop-in replacement.
