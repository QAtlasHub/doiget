doiget provenance migrate — one-shot v1 → v2 migration tool (ADR-0024, docs/PROVENANCE_LOG.md §“Schema migration”).

The migration is one-shot (the resulting v2 log re-reading as v2 is a no-op on re-run), idempotent, and dry-runnable via --dry-run. See doiget_core::provenance::migrate_v1_to_v2 for the binding implementation.

Resolves the log path the same way super::audit_log::run does: DOIGET_LOG_PATH env, falling back to <config_dir>/doiget/access.jsonl.

Output goes to stdout via writeln! against an explicit stdout().lock() — the sanctioned escape hatch for human-facing CLI surfaces (workspace lints deny print_stdout to keep MCP stdio safe).
